# Lentium Gallery v0.9 — директно качване от компютър

## Какво е добавено

- избор на цяла папка със снимки;
- drag-and-drop на множество изображения;
- качване директно в Supabase Storage bucket `galleries`;
- паралелно качване по 3 файла;
- общ progress bar;
- статус за всеки файл;
- таблица `photos`, свързана с `galleries`;
- публичната галерия автоматично зарежда качените снимки;
- директно изтегляне на отделен кадър;
- автоматичен slug на латиница;
- бутон „Качи снимки“ за всяка галерия в админ панела.

## 1. Задължителен SQL

В Supabase:

SQL Editor → New query

Копирай и изпълни съдържанието на:

`supabase/photos-and-storage.sql`

Това създава таблицата `photos`, индексите, RLS политиките и правилата за Storage.

## 2. Качване на версията

1. Разархивирай ZIP файла.
2. Отвори GitHub repository `lentiumproduction/lentium-gallery`.
3. Add file → Upload files.
4. Качи всички файлове и папки от архива.
5. Commit changes.
6. Изчакай Vercel deployment-ът да стане Ready.

## 3. Работа

1. Влез в `/admin`.
2. Създай нова галерия.
3. След създаването автоматично ще се отвори страницата „Качи снимки“.
4. Избери папката с готовите JPG файлове.
5. Натисни „Започни качването“.
6. След края отвори публичната галерия.

## Важно

- Допускат се JPG, PNG и WebP.
- Максимумът е 50 MB на файл.
- За първия тест използвай 5–10 оптимизирани снимки.
- При сватба с 18 GB файлове ще се използва пространството и трафикът на Supabase Storage. Провери квотите на плана си преди да качиш цялата сватба.
