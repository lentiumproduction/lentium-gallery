# Lentium Gallery v0.8 — качване на корична снимка

## Ново

- drag-and-drop качване на корица;
- визуален преглед преди създаване;
- JPG, PNG и WebP;
- ограничение до 6 MB;
- автоматичен публичен URL от Supabase Storage;
- URL адресът се записва автоматично в таблицата `galleries`;
- вече не се копира адрес на корица ръчно.

## Задължителна SQL стъпка

В Supabase отвори:

SQL Editor → New query

и изпълни съдържанието на:

`supabase/storage-covers.sql`

Този код:
- създава публичен bucket `gallery-covers`;
- ограничава файловете до 6 MB;
- допуска само JPG, PNG и WebP;
- позволява качване, промяна и изтриване само на влезлия потребител.

## Качване на версията

1. Разархивирай ZIP файла.
2. GitHub → `lentiumproduction/lentium-gallery`.
3. Add file → Upload files.
4. Качи съдържанието.
5. Commit changes.
6. Изчакай Vercel да стане Ready.

## Проверка

1. Влез в `/admin`.
2. Натисни „+ Нова галерия“.
3. Плъзни корична снимка до 6 MB.
4. Изчакай „Корицата е качена успешно.“
5. Попълни останалите полета.
6. Натисни „Създай галерията“.
