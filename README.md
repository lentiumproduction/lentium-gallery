# Lentium Gallery v0.5 — Supabase връзка

Тази версия:

- чете публикуваните галерии от таблицата `public.galleries`;
- използва автоматично синхронизираните Vercel/Supabase променливи;
- има резервен режим, ако променливите липсват;
- добавя първа админ страница на `/admin`;
- страницата `/admin` засега е само за проверка и преглед;
- публичната галерия продължава да работи на `/gallery/darina-georgi`.

## Качване

1. Разархивирай ZIP файла.
2. В GitHub отвори `lentiumproduction/lentium-gallery`.
3. `Add file` → `Upload files`.
4. Качи всички файлове и папки от архива.
5. Натисни `Commit changes`.
6. Изчакай Vercel да стане `Ready`.

## Проверка

Отвори:

- `/admin`
- `/gallery/darina-georgi`

Ако в `/admin` се вижда „Дарина & Георги“, сайтът чете успешно от Supabase.

## Сигурност

Тази версия не позволява записване, редактиране или изтриване. Следващата стъпка е Supabase Auth и защитен администраторски вход.
