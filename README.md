# Lentium Gallery v0.6 — защитен админ вход

## Ново

- `/admin` вече изисква вход;
- `/login` съдържа вход с имейл и парола;
- сесиите се пазят в защитени cookies чрез `@supabase/ssr`;
- има бутон „Изход“;
- неоторизиран посетител се пренасочва към `/login`;
- публичната галерия остава достъпна без вход.

## Преди да тестваш

В Supabase създай един администраторски потребител:

1. Authentication → Users.
2. Add user → Create new user.
3. Въведи твой имейл и силна парола.
4. Изключи автоматичното изпращане на покана, ако панелът предлага такава опция.
5. Потвърди създаването.

Не изпращай паролата в чат.

## Качване

1. Разархивирай ZIP файла.
2. GitHub → `lentiumproduction/lentium-gallery`.
3. Add file → Upload files.
4. Качи съдържанието и натисни Commit changes.
5. Изчакай Vercel да стане Ready.

## Проверка

1. Отвори `/admin`.
2. Трябва автоматично да бъдеш изпратен към `/login`.
3. Влез с потребителя, създаден в Supabase.
4. След успешен вход ще се отвори `/admin`.
